# Multi-omics analysis of keratinocytes reveals dermokine-dependent regulation of cell-cell adhesion via p120

Code to accompany manuscript of Canbay et al. 2024 (in preparation)

The repository is organised as follows:

data/ contains compressed (.rds) Spectronaut output tables (for proteome/phosphoproteome data processed from raw mass spectrometry files, available on PRIDE database) and other data used for analysis
results/ contains two further directories: data/ and figures/, containing tabular and image results respectively from the analysis. Figures used in the manuscript can be found in figures/forPaper/
source/ contains all R scripts used for analysis
